# QA Automation Portfolio

Привет! Это мой проект по автоматизации тестирования.
Здесь представлены примеры UI и API тестов, написанных на Python.

### Стек:
* Python (Pytest)
* Selenium WebDriver (Page Object Model)
* Requests (API testing)
* Allure Reports

### Как запустить:
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите тесты: `pytest -v`

*Примечание: Тесты написаны для демонстрации навыков на публичных тестовых стендах (SauceDemo, JSONPlaceholder).*
